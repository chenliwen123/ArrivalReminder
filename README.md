# ArrivalReminder 方案文档（V1→V3 路线）

> 目标：构建一个基于**自定义定位围栏 + 解锁事件**的智能语音提醒与情绪记录系统。
> 当前阶段：架构优化已完成，原生 Demo 待开发。

---

## 1. 定位模块（LocationEngine）

### 设计原则
- ❌ 不使用 Google Geofencing API
- ✅ 使用自定义圆形地理围栏算法

### 实现方式
- `FusedLocationProviderClient` 持续获取位置
- 通过前台服务保持定位活跃
- 使用 Haversine 公式计算当前位置与目标点距离

### 判断逻辑
- `distance < radius` → `inside = true`
- `distance >= radius` → `outside`

### 状态变化触发
- 进入区域：标记“可触发”
- 离开区域：重置触发状态

---

## 2. 解锁监听模块（UnlockDetector）

### 风险说明
- Android 8+ 对隐式广播限制较多，单一解锁广播不稳定。

### 稳定实现方式
组合判断：
- `ACTION_USER_PRESENT`（辅助信号）
- `KeyguardManager.isKeyguardLocked()`（锁屏状态二次确认）
- 前台服务运行状态确认

### 触发流程
解锁事件发生 → 判断是否在区域内 → 判断是否满足冷却/触发条件 → 触发语音。

---

## 3. 触发状态机（TriggerManager）

目标：避免重复提醒。

```text
OUTSIDE
   ↓
INSIDE_NOT_TRIGGERED
   ↓ 解锁
INSIDE_TRIGGERED
   ↓ 离开
OUTSIDE（重置）
```

### 冷却机制
- 每次进入区域仅触发一次
- 用户离开后自动重置
- 不采用固定“凌晨 5 点重置”

## 4. 语音系统（VoiceEngine）

### 第一阶段

- 女声
- 自然语速

- “你到家啦～”
- “你到温泉啦～”
- “该出门咯～”

### 后续升级
可接入：
- 百度语音
- 讯飞语音
- 自定义云端音色

---

## 5. 情绪记录模块（MemoryManager）

### 记录方式
- ⚠️ 不采用自动录音（避免后台录音风险）
- 离开地点时发送通知
- 用户主动点击后输入文字或语音转文字

### 存储结构
每条记录包含：

```json
{
  "locationId": "home",
  "rawText": "今天回家有点累，但看到猫很开心",
  "shortSummary": "回家疲惫但被猫治愈",
  "timestamp": 1736870400000
}
```

---

## 6. AI 摘要模块（AIProcessor）

### 目标
将原始情绪记录生成：
- 20–30 字简短提示
- 同时保留完整原文

### 执行策略
- ❌ 不实时调用
- ✅ 放入待处理队列异步执行

触发条件建议：
- Wi-Fi 可用
- 设备处于充电状态
- 系统空闲时间

避免：
- 电量消耗过快
- 网络失败导致体验不稳定
- 成本不可控

---

## 7. 后台运行策略

Android 10+ 必须使用：
- 前台服务（ForegroundService）
- 常驻通知
- 定位保活
- 解锁监听
- 状态管理

否则可能触发：
- Doze 模式限制
- 后台定位受限
- 进程被系统回收

---

## 8. 权限策略

### 必须申请
- `ACCESS_FINE_LOCATION`
- `FOREGROUND_SERVICE`
- `RECEIVE_BOOT_COMPLETED`
- `RECORD_AUDIO`（仅用户手动触发语音输入时）

### 不申请
- 后台静默录音相关权限
