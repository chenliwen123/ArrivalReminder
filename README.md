# 智能位置提醒系统方案文档

> 目标：实现基于地理位置与解锁事件的个性化语音提醒系统。  
> 状态：原型阶段（方案设计 + 工具测试完成）

---

## 🧭 一、项目目标

实现一个“智能提示”系统，当用户到达特定位置后，  
在解锁手机或触发指定动作时，自动给出语音提示或查看历史留言。

典型使用场景：
- 到家时提醒 “你到家啦～”
- 到温泉、公司、健身房时自动提示
- 离开某地时自动开始录音 / 记录留言

## 🧰 三、技术选型演化

### 1️⃣ 初步方案：MacroDroid + TTS
- 利用 **MacroDroid** 作为自动化引擎；
- 使用系统 **地理围栏** 和 **屏幕解锁事件**；
- 缺点：需依赖 Google Play 服务（部分机型不兼容）。

### 2️⃣ 替代方案：Auto.js 脚本实现
- 优势：
  - 可实现屏幕检测、语音播报；
  - 可与本地文件交互；
- 缺点：
  - 无法直接监听系统广播；
  - 地理围栏需要手动实现（定期定位判断）。

### 3️⃣ 长期方案：原生 Android App（Kotlin / Java）
- 通过系统广播：
  - 监听 `Intent.ACTION_USER_PRESENT`（解锁事件）；
  - 使用 Google Fused Location / 自定义定位逻辑；
- 可实现系统级后台运行；
- 支持自定义语音 / AI 摘要处理；
- **推荐最终方向 ✅**

## ⚙️ 四、实现思路（当前阶段）

### 宏 1：解锁提醒
1. 触发：屏幕解锁  
2. 动作：
   - 延迟 5 秒（等待解锁完成）
   - 获取当前位置
   - 若在目标区域内 → 播放语音提示  
3. 限制：每天仅触发一次（凌晨 5 点重置）

### 宏 2：离开录音
1. 触发：离开指定地理区域  
2. 动作：
   - 自动开始录音  
   - 停止条件：检测静止超过一定时间 / 系统超时停止  
   - 存储录音并触发 AI 摘要提取  

---

## 🧩 五、AI 精简逻辑

- 在留言录入阶段调用 AI 模型（如 GPT）生成摘要；
- 存储两个版本：
  - 简短提示版（20–30 字）；
  - 完整原文记录；
- 解锁提示时优先显示精简版。

## 🧠 六、技术难点与解决方向

| 问题 | 原因 | 解决方向 |
|------|------|-----------|
| MacroDroid 地理围栏失效 | Google API 限制 / MIUI 定位策略 | 改为自定义 GPS 轮询或使用原生定位 |
| Auto.js 无法监听解锁 | 系统广播权限不足 | 改为原生 Android 应用实现 |
| TTS 发音质量不理想 | 系统语音包音色单一 | 考虑使用云端语音接口（如百度/讯飞） |
| 后台运行限制 | Android Doze 模式 | 使用前台服务维持活动状态 |
